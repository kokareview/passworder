  <h1>Как это работает?</h1>
  <h3>Логика оценки</h3>
  <p>Каждый пункт даёт баллы:</p>
  
  | Пункт | Баллы |
  |-------|-------|
  | Минимум 8 символов | +20 |
  | Строчные буквы | +15 |
  | Заглавные буквы | +15 |
  | Цифры | +15 |
  | Спецсимволы | +20 |
  | 12+ символов | +15 |
  | Бонус за 16+ символов | +10 |

  <b>Максимум</b> — 100 баллов.
  <h3>Уровни надёжности</h3>

  | Баллы | Уровень | Цвет |
  |-------|---------|------|
  | 0-29 | Очень слабый | #c0392b |
  | 30-54 | Слабый | #c0392b |
  | 55-74 | Средний | #d68910 |
  | 75-89 | Сильный | #2980b9 |
  | 90-100 | Очень надёжный | #27ae60 |

  <h3>Время взлома</h3>
  <p>Считается по формуле:</p>
  
  ```txt
  комбинации = размер_алфавита ^ длина_пароля
  время = комбинации / 1_000_000_000 / 2
  ```

  <h1></h1> 
  <h3>Размер алфавита:</h3>
  - Строчные (a-z) — 26
  - Заглавные (A-Z) — 26
  - Цифры (0-9) — 10
  - Спецсимволы — 32
  <b>Пример</b>: пароль `Abc123!@` (8 символов, все категории):
  - Алфавит: 26+26+10+32 = 94
  - Комбинаций: 94^8 ≈ 6.09 × 10^15
  - Время: ~3 миллиона секунд ≈ 35 дней
  <b>Примечание</b>: это <b>приблизительная</b> оценка. Реальная скорость взлома зависит от метода атаки, оборудования и других факторов.
  <h1>Настройка</h1>
  <h3>Изменить критерии проверки</h3>
  Сделай форк моего репозитория
  Открой `script.js` и найди функцию `check`:

  ```javascript
  const c = {
    len:     pwd.length >= 8,      // можно поменять на 10 или 12
    lower:   /[a-z]/.test(pwd),
    upper:   /[A-Z]/.test(pwd),
    digit:   /[0-9]/.test(pwd),
    special: /[^A-Za-z0-9]/.test(pwd),
    long:    pwd.length >= 12      // можно поменять
  };
  ```

  <h3>Изменить баллы</h3>
  В той же функции:

  ```javascript
    let score = 0;
    if (c.len)     score += 20;   // поменяй баллы
    if (c.lower)   score += 15;
    // ...
  ```

  <h3>Изменить цвета</h3>
  Открой `style.css` и найди блок `.bar`
  
  ```css
  .bar {
    background: #333;   /* цвет по умолчанию */
  }
  ```

  Цвета уровней задаются в `script.js`:

  ```javascript
  color = '#c0392b';   // слабый
  color = '#d68910';   // средний
  color = '#2980b9';   // сильный
  color = '#27ae60';   // очень надёжный
  ```
